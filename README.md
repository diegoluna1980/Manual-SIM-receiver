# Manual SIM Receiver

A technical documentation for the travelling GNSS receiver of SIM.

## Overview

This repository contains documentation and calibration materials for a manual SIM receiver project. 

## Contents

- **Main.pdf** - Primary documentation for the SIM receiver
- **Main.tex** - LaTeX source file for the main documentation
- **Calibration Sheets** - Spreadsheets for receiver calibration (`PlanillaCalibracionReceptorSIM.odt/pdf`)
- **X0 Calibration** - Calibration documentation for X0 parameter (`PlanillaCalibraciónX0SIM.odt/pdf`)
- **Figures** - Supporting diagrams and illustrations
